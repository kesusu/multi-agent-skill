# 考试预判

> 基于题库覆盖章节、题量分布和易错题分析，预判考试可能出现的题型。

---

## 必考题型（出现概率 > 80%）

### 1. 红宝石激光器 / 三能级系统计算
- **对应章节：** 第6章（电磁场与物质共振相互作用）、第7章（激光振荡特性）
- **预计分值：** 10-15分
- **题库支撑：** 题库中三能级系统相关题目出现多次，属于核心考点
- **解题要点：**
  - 三能级系统阈值条件：Δnt = Nt/2（至少一半粒子需泵浦到上能级）
  - 区分三能级和四能级：红宝石=三能级，Nd:YAG=四能级
  - 粒子数速率方程求解稳态粒子数
  - 注意与红宝石的Cr³⁺离子浓度、能级寿命等参数配合计算

### 2. 谐振腔稳定性判断
- **对应章节：** 第3章（光学谐振腔）
- **预计分值：** 5-10分
- **题库支撑：** 稳定腔笔记单独总结，题库中反复出现
- **解题要点：**
  - g₁ = 1 - L/R₁，g₂ = 1 - L/R₂（**凹面R>0，凸面R<0**）
  - 0 ≤ g₁g₂ ≤ 1 为稳定腔
  - 画图辅助判断镜面凹凸方向
  - 对称腔 g₁ = g₂ 时简化判断

### 3. 高斯光束参数计算
- **对应章节：** 第3章（光学谐振腔 - 高斯光束部分）
- **预计分值：** 10-15分
- **题库支撑：** 高斯光束是谐振腔理论的核心
- **解题要点：**
  - 给 w₀ 和 λ → 求 zR = πw₀²/λ → 求任意 z 处的 w(z) 和 R(z)
  - 远场发散角 θ = λ/(πw₀)
  - q参数变换：用 ABCD 法则
  - 束腰位置的判断（R → ∞ 处）

### 4. 爱因斯坦系数关系及应用
- **对应章节：** 第1章（激光基本原理）
- **预计分值：** 5-10分
- **题库支撑：** 第1章选择题9题+作业9题，覆盖密集
- **解题要点：**
  - A₂₁ = 1/τs
  - B₂₁ = (c³/8πhν³)A₂₁
  - g₁B₁₂ = g₂B₂₁（**别忘简并度**）
  - 热平衡下 N₂/N₁ = (g₂/g₁)exp(-hν/kBT)

## 高频题型（出现概率 50-80%）

### 5. 纵模间隔计算
- **对应章节：** 第3章
- **预计分值：** 5-8分
- **题库支撑：** 作业和测验中多次出现
- **解题要点：**
  - **Δνq = c/(2L')**，L' = nL（光学长度）
  - **单位换算是最大陷阱：** 腔长用cm要换m，折射率要乘
  - 求纵模个数：Δν（增益带宽）/ Δνq
  - 激光频率 νq = qc/(2L')

### 6. 谱线加宽计算（自然/碰撞/多普勒）
- **对应章节：** 第6章（课程第4章）
- **预计分值：** 8-12分
- **题库支撑：** 测验10题+作业3题
- **解题要点：**
  - 自然加宽 ΔνN = 1/(2πτs) — 洛伦兹线型
  - 碰撞加宽 ΔνL = αp — 洛伦兹线型
  - 多普勒加宽 ΔνD = (2ν₀/c)√(2kBT·ln2/m) — 高斯线型
  - **注意区分线型：** 均匀加宽=洛伦兹，非均匀加宽=高斯
  - 线型函数的归一化 ∫g(ν)dν = 1

### 7. 增益饱和与阈值条件
- **对应章节：** 第7章（课程第5章）
- **预计分值：** 8-12分
- **题库支撑：** 测验10题
- **解题要点：**
  - 阈值增益 gt = δ/L
  - 小信号增益 g⁰ = Δn⁰·σ
  - 增益饱和公式 g(I) = g⁰/(1 + I/Is)
  - 均匀加宽 vs 非均匀加宽的饱和行为差异（烧孔效应）

### 8. 光子寿命和Q值
- **对应章节：** 第3章
- **预计分值：** 5分
- **题库支撑：** 基础概念题
- **解题要点：**
  - τc = L'/(cδ)
  - Q = 2πντc
  - Q = ν/Δν（谐振峰带宽定义）
  - δ越大 → τc越小 → Q越低

## 可能出现的题型（30-50%）

### 9. 等价共焦腔位置
- **对应章节：** 第3章
- **预计分值：** 5-8分
- **题库支撑：** 笔记中专门总结
- **解题要点：**
  - 任意稳定腔等价于某个共焦腔
  - 等价腔的束腰位置和束腰半径
  - 公式较复杂，**建议画图推导**而非死记
  - 对称腔（R₁ = R₂）时简化计算

### 10. 光线矩阵传输计算
- **对应章节：** 第3章
- **预计分值：** 5-8分
- **题库支撑：** 基础工具
- **解题要点：**
  - 自由空间 [1,d;0,1]，薄透镜 [1,0;-1/f,1]
  - 矩阵乘法顺序：从右到左
  - 用ABCD矩阵 + ABCD法则求 q 参数变换
  - 等价焦距：多透镜组合的总矩阵

### 11. 模式密度计算
- **对应章节：** 第1章
- **预计分值：** 5分
- **题库支撑：** 第1章选择题
- **解题要点：**
  - n(ν) = 8πν²/c³（含2个偏振）
  - 从波长表达式 n(λ) = 8π/λ⁴
  - 物理含义：单位体积、单位频率/波长间隔内的模式数

### 12. 粒子数比值（玻尔兹曼分布）
- **对应章节：** 第1章、第6章
- **预计分值：** 5分
- **题库支撑：** 题库中多次出现，易错
- **解题要点：**
  - N₂/N₁ = (g₂/g₁)·exp(-hν/kBT)
  - 室温下 N₂/N₁ 极小（约 10⁻³⁰ 量级），所以需要泵浦才能实现反转
  - 注意 kBT 在室温下约 0.026 eV = 4.14×10⁻²¹ J

## 基础送分题（必出）

### 13. 波长-频率-能量换算
- **解题要点：** λν = c，E = hν = hc/λ
- **注意单位：** nm→m 要 ×10⁻⁹

### 14. 激光器基本组成和特性
- 三要素：增益介质、泵浦源、谐振腔
- 激光四特性：单色性、方向性、相干性、高亮度

### 15. 四能级 vs 三能级的区别
- 三能级（红宝石）：下能级=基态，阈值高，效率低
- 四能级（Nd:YAG）：下能级接近基态但非基态，阈值低，效率高

### 16. 均匀加宽 vs 非均匀加宽的区分
- 均匀：自然加宽、碰撞加宽（洛伦兹线型，所有粒子贡献相同）
- 非均匀：多普勒加宽（高斯线型，不同速度粒子贡献不同频率）

## 考试策略建议

### 时间分配
- 选择/填空题：快速过，概念题不超过1分钟/题
- 计算题：留足时间，红宝石系统和高斯光束是大分值

### 高频易错清单（考前过一遍）
1. **纵模间隔公式中 L' = nL**，忘记折射率是丢分最惨的
2. **稳定腔判断中 R 的符号**：凹面正、凸面负
3. **爱因斯坦系数中简并度 g₁、g₂**
4. **谱线加宽的线型**：均匀=洛伦兹，多普勒=高斯
5. **三能级系统的阈值**：Δnt = Nt/2（不是Nt）
6. **高斯光束 z = 0 处 R → ∞**（平面波前）
7. **光子能量单位**：题目给eV时注意换算

### 开卷考试策略
- 这份速查表和公式表放在一起，按目录快速定位
- 计算题先写公式再代数，公式本身有分
- 不确定的题先跳过，回头再查公式
