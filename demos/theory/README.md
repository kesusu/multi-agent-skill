# 理论文档 Demo

同一主题（"AI 时代你真正的活儿是什么"——从焦虑到行动的定位框架）的两个版本，由多 Agent 团队经 4 轮迭代产出。

## 两个版本的关系

| 文件 | 定位 | 推荐 |
|:---|:---|:---|
| `theory_v3.3_CS OR EE.md` | CS/EE 专业版，更完整 | **推荐** |
| `theory_v3.3建议看另外一个更好的版本.md` | 通用版，文科生友好入口 | 可选 |

## 为什么有两个版本

初版对文科生不可读（术语太多）→ 场景测试员发现 → 重写通用入口 → 但 CS/EE 版本保留了更多技术细节。

文件名 "建议看另外一个更好的版本" 是有意为之——引导读者优先看 CS/EE 版。
