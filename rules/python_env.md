# Python 项目默认配置

## Python 版本

用户电脑有多个 Python 版本（3.8、3.11、3.13），**默认使用 Python 3.11**：

```
C:\Users\ke\AppData\Local\Programs\Python\Python311\python.exe
```

非必要不切换版本，切换须经用户确认。

## 已安装的工具库

- **python-pptx 1.0.2** — 生成 PPT 文件（PowerPoint .pptx）
- **python-docx** — 生成 Word 文档（见 `rules/word_format.md` 排版规范）
