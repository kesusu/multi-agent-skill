# 自动批准摘要格式

任务中有自批执行的操作时，回复结尾附此摘要。

## 格式

```text
**自动批准摘要：**
- 自批操作：<类别：写文件/运行脚本/安装依赖/联网/终止进程>
- 关键文件/命令：<只列重要的>
- 风险边界：未删除大量文件；未覆盖用户原始资料；未未经确认的force push；未暴露密钥。
- 验证结果：<结果或失败原因>
```

## 规则

- 只读操作（Read/Grep/Glob/ls）不需要摘要。
- 不为每个命令写流水账，只记录有监督价值的操作。
- 如果触及高风险边界（如 force push、删除文件），明确说明并说明已获得用户确认。
- 用户主动调用 `/permission-summary` 时，按 `commands/permission-summary.md` 的完整格式输出。
