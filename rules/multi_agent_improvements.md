# Multi-Agent 速查卡

实战触发条件速查。完整流程见 multi-agent skill。

## Critic 必须派

修改涉及以下任一：
- 副作用系统（状态管理、事件监听、物理引擎、音频播放）
- 生命周期管理（启动/停止/重启/清理）
- 跨 3+ 集成点
- 主 AI 说"我觉得没问题"

## Critic 可跳过

严格限定：纯粹文本/配置修改 · 已有自动化测试 · 用户明确说"直接改"

## Agent 产出验证

Agent 声称已修改 → 不可信。必须 Read 验证客观证据（diff、文件内容），主 AI 自己执行 Edit/Write。

## 交付前自测

1. 能加载（无报错）→ 2. 核心路径通 → 3. 重试路径通（状态干净）→ 4. 回归检查 → 5. 边界路径

## 用户情绪信号

感受到用户质疑或不满时，退一步审视全局，不只修具体问题。用 LLM 理解力判断，不做关键词匹配。
